# BNB next technical stage

1. GitHub CI installs dependencies.
2. Run JavaScript checks.
3. Compile Solidity.
4. Run the full Hardhat test suite.
5. Fix every failure.
6. Deploy to BNB Testnet only.
7. Record and verify the deployed contract address.
8. Configure the frontend with the verified contract address.
9. Exercise group creation, membership, admin approvals, lock, contributions, bidding, settlement, withdrawals, defaults, waitlist and refunds.
10. Only after testnet acceptance prepare mainnet configuration.

Never commit a private key, seed phrase, API key, or .env file.
