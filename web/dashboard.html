Primary pilot route: link your WhatsApp number above, then send VERIFY to the Liholiswano WhatsApp account and complete the short verification conversation.

The legacy Stage-A form remains available only for development/compliance tooling; it is not required for Testnet pilot financial access.

The current Stage-A implementation records the file's type, size and SHA-256 fingerprint only. It does not store the identity document on Render.
